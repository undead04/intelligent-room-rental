# Skill: Summarize Session (Chuyển Session Mượt Mà)

Kích hoạt skill này khi người dùng muốn đổi sang phiên chat mới hoặc gõ lệnh tóm tắt:

## Đầu ra bắt buộc gồm 3 phần:
1. **Trạng thái hiện tại:** Dự án đang làm đến đâu? Tính năng nào đã xong và chạy tốt?
2. **Các file quan trọng đã sửa/tạo mới:** Danh sách đường dẫn file kèm chức năng tóm tắt 1 câu.
3. **Prompt tiếp theo để dán vào session mới:** Một đoạn văn bản ngắn gọn để người dùng chỉ việc copy-paste vào session mới là agent mới tiếp tục công việc ngay lập tức.
